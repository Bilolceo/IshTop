# EMAIL PRODUCTION CONFIGURATION GUIDE

## Option 1: Gmail SMTP (Free, but less reliable for production)
# Requirements: Gmail account + App Password
# Steps:
# 1. Enable 2FA on Gmail account
# 2. Generate App Password: https://myaccount.google.com/apppasswords
# 3. Use the 16-character password (not your regular password)

## Current Gmail SMTP Settings:
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-gmail@gmail.com
SMTP_PASSWORD=your-16-char-app-password
SMTP_FROM_EMAIL=noreply@yourdomain.com
SMTP_FROM_NAME="SmartCareer AI"
SMTP_USE_TLS=true

## Option 2: SendGrid (Recommended for Production)
# Visit: https://sendgrid.com
# Free tier: 100 emails/day
# Paid: $14.95/month for 50K emails
# 
# SENDGRID_API_KEY=SG.your-sendgrid-api-key-here
